# Hyperion 

A custom made Atomic linux OS for gaming, AI/ML, 3D and general use. 

## NOTE - this currently ships with NVIDIA drivers, however this is subject to change as this will be tailored for my own rig(s)

### SECURE BOOT IS NOT SUPPORTED AS OF YET
