# Hyperion

![Hyperion Logo](https://raw.githubusercontent.com/tj5miniop/hyperion/refs/heads/main/branding/hyperion-logo.png)

**A custom-made Atomic Operating System** 
*Based on [Fedora Linux](https://fedoraproject.org/) and [Universal Blue](https://universal-blue.org/)*

---

## 📌 Important Notes

- **Current State**: Ships with NVIDIA drivers (subject to change as this OS is tailored my personal rig)
- **Secure Boot**: Currently not supported - may be reworked in the future - see [this issue](https://github.com/tj5miniop/hyperion/issues/3)

---

## 🎯 Features

- Optimized for gaming performance
- AI/ML and 3D application support (These apps aren't installed by default as of yet, but the system itself should have the correct dependencies)
- Based on Fedora Linux and Universal Blue

## 🛠️ Technical Details

- **Base System**: Fedora Linux
- **Distribution**: Universal Blue
- **Kernel**: OGC kernel ( created by the Open Gaming Collective, used in [Bazzite](https://bazzite.gg))
- **Drivers**: NVIDIA, AMD & Intel drivers all installed
